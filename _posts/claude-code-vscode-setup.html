핵심 요약

  • VS Code는 무료 편집기입니다. 파일 목록과 터미널을 한 화면에서 볼 수 있습니다.
  • 바탕화면에 연습용 폴더를 하나 만들고, VS Code로 그 폴더를 엽니다.
  • VS Code 안에서 터미널을 열고 claude를 실행하면 그 폴더가 작업 자리가 됩니다.

이 글은 클로드 코드 왕초보 시리즈의 다섯 번째 글입니다. 앞 글에서 설치를 마쳤다면, 이제 클로드가 일할 자리를 만들어 줄 차례입니다. 클로드 코드는 "지금 열려 있는 폴더" 안에서 일합니다. 그래서 아무 데서나 실행하면 클로드가 어디에 파일을 만들어야 할지 모릅니다.

VS Code(브이에스 코드)는 마이크로소프트가 무료로 나눠 주는 편집기입니다. 편집기는 글자로 된 파일을 만들고 고치는 프로그램입니다. 메모장과 비슷하지만, 왼쪽에 폴더 안 파일 목록이 보이고 아래쪽에 터미널(글자로 컴퓨터에 말을 거는 창)을 같이 띄울 수 있습니다. 클로드가 만든 파일이 눈앞에서 바로 생기는 것을 볼 수 있다는 점이 가장 큽니다. 터미널만 쓰면 파일이 생겼는지 안 생겼는지 알 수가 없어서 답답합니다.

1단계 · VS Code 내려받아 설치하기

  1. 브라우저 주소창에 code.visualstudio.com/download를 입력하고 엽니다.
  2. 윈도우를 쓰면 Windows, 맥을 쓰면 macOS 아래의 내려받기 단추를 누릅니다.
  3. 윈도우는 VSCodeUserSetup으로 시작하는 설치 파일이 내려받아집니다. 두 번 눌러 실행합니다. 이 설치본은 관리자 암호를 묻지 않습니다.
  4. 설치 창에서 동의에 표시하고 Next를 계속 누른 뒤 Install을 누릅니다. 중간에 나오는 선택지는 그대로 두면 됩니다.
  5. 맥은 내려받은 파일의 압축이 풀리면 Visual Studio Code를 응용 프로그램 폴더로 끌어다 놓습니다.

설치가 끝나고 VS Code를 처음 열면 메뉴가 영어로 나옵니다. 놀라지 마십시오. 이 글에서 쓰는 메뉴는 네 개뿐이라 영어 그대로 따라 하셔도 됩니다.

2단계 · 연습 폴더 만들기

클로드가 어질러도 괜찮은 빈 폴더가 하나 필요합니다. 중요한 서류가 들어 있는 폴더에서 연습하지 마십시오.

  1. 바탕화면에서 마우스 오른쪽 단추를 누릅니다.
  2. 윈도우는 새로 만들기 > 폴더, 맥은 새로운 폴더를 고릅니다.
  3. 폴더 이름을 claude-practice라고 적고 Enter를 누릅니다.

이름은 영문 소문자와 붙임표만 썼습니다. 나중에 터미널에 폴더 이름을 직접 쳐 넣을 일이 생기는데, 그때 한글이나 빈칸이 섞여 있으면 손이 많이 갑니다.

3단계 · VS Code로 폴더 열기

  1. VS Code를 실행합니다.
  2. 위쪽 메뉴에서 File > Open Folder...를 고릅니다. (맥은 File > Open...)
  3. 방금 만든 claude-practice 폴더를 한 번만 눌러 고른 뒤 폴더 선택을 누릅니다. 폴더 안으로 들어가서 고르는 것이 아니라, 폴더 자체를 고르는 것입니다.
  4. "이 폴더에 있는 파일 작성자를 신뢰합니까?"라는 물음이 나오면 Yes, I trust the authors를 누릅니다. 내가 방금 만든 빈 폴더이니 괜찮습니다.

왼쪽에 CLAUDE-PRACTICE라고 폴더 이름이 대문자로 뜨면 성공입니다. 아직 아무 파일도 없으니 그 아래는 비어 있는 것이 정상입니다.

여기서 제일 많이 막힙니다 파일 하나를 열지 말고 폴더를 여십시오. 파일만 열면 왼쪽 목록이 안 생기고, 터미널을 열어도 엉뚱한 위치에서 시작합니다. 왼쪽에 폴더 이름이 보이는지부터 확인하세요.

4단계 · VS Code 안에서 터미널 열기

  1. 위쪽 메뉴에서 Terminal > New Terminal을 고릅니다.
  2. 단축키로는 Ctrl + ` 입니다. 마지막 키는 숫자 1 왼쪽에 있는 키입니다. 맥은 Control + ` 입니다.
  3. 화면 아래쪽에 까만 칸이 열리고, 줄 앞에 폴더 위치가 적혀 있습니다. 끝이 claude-practice로 끝나면 제자리에 온 것입니다.

여기가 앞으로 클로드에게 말을 걸 자리입니다. 잘 왔는지 확인해 보겠습니다. 아래 한 줄을 그대로 치고 Enter를 누르십시오.

claude --version

다음처럼 숫자와 (Claude Code)가 같이 나오면 정상입니다. 숫자는 사람마다 다릅니다.

'claude' is not recognized나 command not found: claude라고 나오면 설치가 아직 안 끝난 것입니다. VS Code를 완전히 껐다 다시 여는 것부터 해 보시고, 그래도 같으면 설치 편을 다시 보십시오.

터미널 대신 화면에서 쓰고 싶다면

공식적으로 VS Code용 Claude Code 확장 프로그램도 나와 있습니다. 대화를 창 안에서 주고받고, 클로드가 고친 부분을 색으로 비교해 보여 줍니다. VS Code 1.94 이상이 필요합니다.

  1. Ctrl + Shift + X(맥은 Cmd + Shift + X)를 눌러 확장 프로그램 목록을 엽니다.
  2. 검색칸에 Claude Code를 적고, 나온 항목의 설치를 누릅니다.
  3. 설치한 뒤에도 확장 프로그램이 안 보이면 VS Code를 다시 시작합니다.

다만 이 확장 프로그램은 자기 몫의 프로그램을 따로 품고 있어서, 터미널에서 claude를 치는 것과는 별개입니다. 터미널에서도 쓰려면 앞 글에서 한 설치가 그대로 필요합니다. 이 시리즈는 터미널을 기준으로 이어 갑니다. 둘 중 어느 쪽이든 상관없지만, 처음에는 한 가지만 쓰는 편이 헷갈리지 않습니다.

자주 묻는 질문

VS Code를 꼭 깔아야 하나요?

아닙니다. 클로드 코드는 윈도우의 PowerShell이나 맥의 터미널에서도 똑같이 돌아갑니다. 다만 클로드가 만든 파일이 눈에 보이지 않아서 초보자에게는 답답합니다. 파일 목록과 터미널을 한 화면에서 보려고 까는 것입니다.

메뉴가 영어라 못 찾겠습니다.

이 글에서 쓰는 메뉴는 위쪽 줄의 File과 Terminal 두 개뿐입니다. File은 맨 왼쪽, Terminal은 그 오른쪽에 있습니다. 눌러 보고 아니면 닫으면 되니 부담 없이 눌러 보십시오.

연습 폴더를 나중에 지워도 되나요?

됩니다. 안에 든 것이 연습용 파일뿐이라면 폴더째 휴지통에 넣어도 클로드 코드 자체에는 아무 일이 없습니다. 다만 폴더를 지우기 전에 터미널 창은 닫아 두는 편이 깔끔합니다.
