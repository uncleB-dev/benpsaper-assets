핵심 요약

  • prompts.chat은 무료로 쓸 수 있는 오픈소스 프롬프트 모음입니다. 프롬프트 데이터는 CC0(저작권을 내려놓은 공개 자료)입니다.
  • 주소 https://prompts.chat/api/mcp 하나를 내 AI 도구에 연결하면, 사이트에 들어가 복사할 필요 없이 AI가 직접 찾아서 씁니다.
  • 클로드·ChatGPT·제미나이·커서마다 연결하는 자리가 다릅니다. 도구별로 정리했고, 검색은 영어 낱말로 해야 잘 잡힙니다.

좋은 프롬프트(AI에게 주는 지시문)를 모아 둔 사이트는 많습니다. 문제는 매번 사이트에 들어가서 찾고, 복사하고, 채팅창에 붙여 넣어야 한다는 점입니다. 이 글은 그 과정을 AI에게 넘기는 방법을 다룹니다. "블로그 글쓰기 프롬프트 찾아서 이 주제로 초안 써 줘"라고 말하면, AI가 프롬프트 모음을 직접 검색해 알맞은 것을 꺼내 쓰게 만드는 것입니다.

이때 쓰는 연결 방식을 MCP라고 부릅니다. MCP는 AI 앱에 바깥 도구를 꽂는 공통 규격입니다. USB 단자처럼 모양이 정해져 있어서, 한 번 만든 도구를 여러 AI 앱에 똑같이 꽂을 수 있습니다. 아래에서 도구별로 어디에 꽂는지 차례로 보겠습니다.

prompts.chat은 무엇이고, 연결하면 무엇이 달라지나

prompts.chat은 예전 이름이 Awesome ChatGPT Prompts였던 프롬프트 모음입니다. 깃허브(GitHub, 프로그램 코드를 공개해 두는 사이트)에 f/prompts.chat이라는 이름으로 공개돼 있고, 2022년 12월부터 이어져 왔습니다. 처음에는 ChatGPT용으로 시작했지만 지금은 클로드·제미나이 같은 다른 AI에도 그대로 쓸 수 있다고 안내합니다.

  • 프롬프트: 저장소에 공개된 데이터 파일(prompts.csv)을 2026-09-19에 세어 보니 2,169개가 들어 있었습니다. 사람들이 계속 올리기 때문에 숫자는 늘어납니다.
  • 스킬: 지시문 여러 개와 참고 파일을 한 폴더로 묶은 것입니다. AI가 특정 일을 할 때 꺼내 쓰는 작업 설명서라고 보면 됩니다.
  • 라이선스: 프롬프트 내용과 데이터는 CC0 1.0, 사이트 프로그램 코드는 MIT 라이선스입니다. 사이트 질문 답변에도 상업적 용도를 포함해 출처 표시 없이 자유롭게 써도 된다고 적혀 있습니다.

연결하면 AI가 쓸 수 있는 기능이 생깁니다. 서버가 알려 주는 기능 목록을 직접 불러와 보니, 프롬프트 검색(search_prompts), 프롬프트 꺼내기(get_prompt), 프롬프트 다듬기(improve_prompt), 스킬 검색(search_skills), 스킬 꺼내기(get_skill) 같은 것들이 있었습니다. 프롬프트 안에 {{주제}}처럼 빈칸이 있으면 AI가 그 빈칸에 들어갈 내용을 물어보고 채워 줍니다. 저장하기 같은 기능도 있지만 prompts.chat 계정의 API 키(내 계정임을 증명하는 열쇠 문자열)가 있어야 합니다. 찾아서 쓰기만 할 거라면 키는 없어도 됩니다.

한눈에 보기 — 내 도구는 어디에 연결하나

같은 회사 제품이라도 채팅 앱과 터미널(글자로 컴퓨터에 말을 거는 창)용 프로그램은 연결하는 자리가 다릅니다. 2026년 9월에 각 회사 공식 문서를 확인한 결과입니다.

도구채팅 앱터미널·편집기
클로드됩니다. 사용자 지정 커넥터로 추가. 무료 계정은 1개까지클로드 코드: 플러그인 또는 claude mcp add
ChatGPT웹에서 개발자 모드를 켜야 합니다. Plus·Pro·Business·Enterprise·Education 계정Codex CLI: codex mcp add
제미나이개인 계정용 기능이 있으나 미국·만 18세 이상·영어에서만 됩니다Gemini CLI: gemini mcp add
커서해당 없음설정 파일 mcp.json에 주소 적기

어느 도구든 넣는 주소는 똑같습니다.

https://prompts.chat/api/mcp

이 주소를 브라우저에 그냥 열면 오류 비슷한 글자만 보입니다. 사람이 보는 웹페이지가 아니라 AI 앱이 대화하는 창구라서 그렇습니다. 고장이 아닙니다.

클로드에 연결하기

① 클로드 앱(웹·데스크톱)

클로드 도움말은 이 기능을 "원격 MCP를 이용한 사용자 지정 커넥터"라고 부릅니다. Free·Pro·Max·Team·Enterprise 모두 쓸 수 있고, 무료 계정은 사용자 지정 커넥터를 1개까지 추가할 수 있습니다.

  1. claude.ai에 로그인하고 Customize > Connectors 화면으로 갑니다. 주소창에 claude.ai/customize/connectors를 쳐도 됩니다.
  2. +를 누르고 Add custom connector를 고릅니다.
  3. 서버 주소 칸에 https://prompts.chat/api/mcp를 붙여 넣습니다.
  4. Advanced settings(OAuth 정보 넣는 칸)는 비워 둡니다. 검색만 할 거라면 필요 없습니다.
  5. Add를 눌러 마칩니다.
  6. 새 대화에서 입력창 왼쪽 아래 +를 누르고 Connectors에서 방금 추가한 것을 켭니다. 대화마다 켜고 끌 수 있습니다.

Team·Enterprise 요금제는 먼저 관리자가 조직 설정에서 추가해 줘야 합니다. 메뉴 이름은 앱이 바뀌면서 달라질 수 있습니다. 한국어로 표시되는 화면이면 비슷한 뜻의 이름을 찾으십시오.

② 클로드 코드 — 플러그인으로 한 번에

prompts.chat은 클로드 코드용 공식 플러그인(기능 꾸러미)을 따로 내놓았습니다. 클로드 코드를 실행한 뒤 아래 두 줄을 차례로 입력합니다. 클로드 코드를 아직 설치하지 않았다면 글 끝의 목차 페이지에서 설치 편부터 보십시오.

/plugin marketplace add f/prompts.chat
/plugin install prompts.chat@prompts.chat
  1. 첫 줄은 prompts.chat의 플러그인 목록을 등록만 합니다. 이 단계에서는 아직 아무것도 설치되지 않습니다.
  2. 둘째 줄을 입력하면 설치 범위를 고르는 화면이 나옵니다. 모든 폴더에서 쓰려면 User scope를 고릅니다.
  3. 설치 요약에 Plugin is now active.가 나오면 바로 쓸 수 있습니다. Run /reload-plugins to activate.가 나오면 클로드 코드가 알아서 다시 불러옵니다.

설치하면 검색 명령 두 개가 생깁니다. 첫 줄은 프롬프트, 둘째 줄은 스킬을 찾습니다.

/prompts.chat:prompts blog writer
/prompts.chat:skills documentation

이 플러그인에는 "프롬프트 찾아 줘", "스킬 설치해 줘" 같은 말에 저절로 켜지는 스킬도 함께 들어 있습니다. 그래서 명령을 외우지 않고 말로 부탁해도 됩니다.

③ 클로드 코드 — 명령 한 줄로 서버만

플러그인 없이 연결만 하고 싶다면 터미널에서 아래 한 줄을 입력합니다. 클로드 코드 안이 아니라, claude를 실행하기 전의 터미널입니다.

claude mcp add --transport http prompts-chat --scope user https://prompts.chat/api/mcp

--scope user를 빼면 지금 있는 폴더에서만 연결됩니다. 공식 문서상 기본값이 "현재 프로젝트만"이기 때문입니다. 성공하면 Added로 시작하는 줄이 나옵니다. 제대로 붙었는지는 아래 명령으로 확인합니다.

claude mcp list

이름 옆에 ✔ Connected가 보이면 정상입니다. ✘ Failed to connect가 보이면 인터넷 연결과 주소 오타부터 확인하십시오.

둘 중 하나만 하십시오 플러그인에는 같은 서버 연결이 이미 들어 있습니다. 플러그인을 설치했다면 ③은 하지 않아도 됩니다. 또 클로드 코드 공식 문서에 따르면 claude.ai 계정으로 로그인한 클로드 코드는 claude.ai에서 추가한 커넥터를 자동으로 가져다 씁니다. 앱에서 이미 연결했다면 클로드 코드에서 따로 안 해도 되는지 먼저 /mcp로 확인해 보십시오.

ChatGPT와 Codex에 연결하기

① ChatGPT 웹 — 개발자 모드

OpenAI 개발자 문서는 개발자 모드를 웹에서, Pro·Plus·Business·Enterprise·Education 계정이 쓸 수 있다고 적고 있습니다. 무료 계정은 목록에 없습니다.

  1. 웹 ChatGPT의 설정에서 Security and login으로 가서 Developer mode를 켭니다.
  2. 앱(Plugins) 화면에서 +를 눌러 개발자 모드용 앱을 새로 만듭니다.
  3. MCP 서버 주소에 https://prompts.chat/api/mcp를 넣습니다.
  4. 인증 방식은 No Authentication(인증 없음)을 고릅니다. 문서가 밝힌 선택지는 OAuth, No Authentication, Mixed 세 가지입니다.
  5. 대화창의 + 메뉴에서 Developer mode를 고르고 방금 만든 앱을 켭니다.

공식 문서는 이 모드를 "위험도가 높다(Elevated risk)"고 표시합니다. 외부 서버가 AI를 속이는 문장을 섞어 보낼 수 있고, 쓰기 작업이 잘못 실행될 수 있어서입니다. 문서도 앱 이름과 기능 이름을 말에 분명히 넣어 부탁하라고 권합니다. 예를 들면 "prompts.chat 앱의 search_prompts로 찾아 줘"입니다. 메뉴 이름은 수시로 바뀌니, 화면이 다르면 설정 안에서 비슷한 이름을 찾으십시오.

② Codex CLI

Codex CLI는 OpenAI가 만든 터미널용 AI 도구입니다. 처음 실행할 때 Sign in with ChatGPT로 로그인합니다. 설치 방법은 운영체제마다 달라서 글 끝의 공식 문서를 보십시오. 설치했다면 터미널에 아래 한 줄을 입력합니다.

codex mcp add prompts-chat --url https://prompts.chat/api/mcp

Codex 코드에 들어 있는 안내 문구대로라면 Added global MCP server 'prompts-chat'.라고 나옵니다. 설정은 내 사용자 폴더 안의 .codex/config.toml 파일에 저장됩니다. 확인은 codex mcp list로 하거나, Codex 안에서 /mcp를 입력하면 됩니다. 공식 문서에 따르면 Codex의 편집기 확장 프로그램도 같은 설정 파일을 읽습니다.

제미나이와 커서에 연결하기

① 제미나이 앱은 한국에서 아직 어렵습니다

구글 도움말에는 개인 구글 계정의 제미나이 웹 앱에서 MCP 서버 주소로 사용자 지정 앱을 추가하는 방법이 있습니다. 다만 조건이 붙어 있습니다. 만 18세 이상이면서 미국에 있어야 하고, 영어로만 쓸 수 있습니다. 회사·학교 계정도 안 됩니다. 한국에서 쓰는 분이라면 지금은 아래 Gemini CLI가 현실적인 길입니다.

② Gemini CLI

Gemini CLI는 구글이 공개한 터미널용 제미나이 프로그램입니다. Node.js(프로그램을 돌리는 바탕 프로그램)가 깔려 있다면 아래 한 줄로 설치합니다. 맥에서 Homebrew를 쓴다면 brew install gemini-cli도 됩니다.

npm install -g @google/gemini-cli
  1. 터미널에 gemini를 입력해 실행합니다.
  2. Sign in with Google을 고르면 브라우저가 열립니다. 개인 구글 계정으로 로그인합니다.
  3. 공식 안내(2026년 9월 기준)에는 이 방식의 무료 사용량이 분당 60회, 하루 1,000회 요청으로 적혀 있습니다. 한도는 바뀔 수 있습니다.
  4. 제미나이를 끄고 터미널로 돌아와 아래 줄을 입력합니다.
gemini mcp add --transport http -s user prompts-chat https://prompts.chat/api/mcp

-s user를 빼면 지금 있는 폴더에만 저장됩니다. 공식 문서상 기본값이 프로젝트(현재 폴더)이기 때문입니다. gemini mcp list를 입력해 prompts-chat 줄 끝에 Connected가 보이면 정상입니다.

prompts.chat 사이트의 설정 안내는 제미나이용으로 --transport sse를 보여 줍니다. 그런데 이 서버는 HTTP 방식으로 응답했고, Gemini CLI 문서도 이 방식의 서버에는 --transport http를 쓰라고 안내합니다. 이 글은 공식 문서를 따랐습니다.

③ 커서(Cursor)

커서는 AI가 들어간 코드 편집기입니다. 모든 폴더에서 쓰려면 내 사용자 폴더 안의 .cursor/mcp.json 파일에, 한 폴더에서만 쓰려면 그 폴더 안의 .cursor/mcp.json에 아래 내용을 적습니다. 윈도우라면 사용자 폴더는 보통 C:\Users\내 이름입니다.

{
  "mcpServers": {
    "prompts-chat": {
      "url": "https://prompts.chat/api/mcp"
    }
  }
}

파일에 이미 다른 서버가 적혀 있다면, 중괄호를 통째로 덮어쓰지 말고 "mcpServers" 안에 "prompts-chat" 덩어리만 끼워 넣으십시오. 쉼표 하나가 빠져도 설정 전체가 읽히지 않습니다.

연결한 뒤 쓰는 법 세 가지

1. 찾아서 골라 쓰기

먼저 후보를 보고 고르는 방법입니다. 결과를 우리말로 설명해 달라고 덧붙이면 편합니다.

prompts.chat에서 "blog writer"로 프롬프트를 찾아서 제목과 한 줄 설명을 한국어로 보여 줘

마음에 드는 번호를 말하면 AI가 그 프롬프트를 꺼내 옵니다. 빈칸이 있으면 무엇을 넣을지 물어봅니다.

2. 일만 시키고 알아서 꺼내 쓰게 하기

고르는 과정까지 맡기는 방법입니다.

prompts.chat에서 알맞은 프롬프트를 찾아 적용해서, "엑셀 VLOOKUP 처음 쓰는 법"을 주제로 블로그 초안을 한국어로 써 줘. 어떤 프롬프트를 썼는지도 알려 줘

마지막 문장이 중요합니다. 어떤 프롬프트를 썼는지 밝히게 해야 결과가 엉뚱할 때 원인을 찾을 수 있습니다.

3. 스킬로 넣어 두고 늘 쓰기 (클로드 코드)

자주 쓰는 스킬은 내 컴퓨터에 설치해 둘 수 있습니다. 클로드 코드 공식 문서에 따르면 내 사용자 폴더의 .claude/skills/스킬이름/SKILL.md에 둔 스킬은 모든 프로젝트에서 쓸 수 있습니다. SKILL.md 맨 위에는 이름(name)과 설명(description)이 적혀 있고, 클로드는 이 설명을 보고 필요할 때 스킬을 스스로 불러옵니다. /스킬이름으로 직접 부를 수도 있습니다.

prompts.chat에서 documentation 스킬을 찾아서 후보를 보여 줘. 내가 고르면 ~/.claude/skills 폴더에 설치해 줘

폴더를 말하지 않으면 지금 작업 중인 폴더의 .claude/skills에 저장될 수 있습니다. prompts.chat 서버의 스킬 꺼내기 기능 설명이 그렇게 안내하기 때문입니다. 모든 곳에서 쓰려면 위처럼 폴더를 분명히 말하십시오.

검색은 영어로 하십시오 2026-09-19에 서버 검색 기능을 직접 불러 확인해 보니 블로그 초안, 요약, 번역, 이메일, 엑셀은 모두 0건이었습니다. blog writer, translator, summarize처럼 영어로 넣었을 때 결과가 나왔습니다. blog writer처럼 두 낱말로 좁히면 더 맞는 것이 나왔습니다. 올라온 글 대부분이 영어라서 그렇습니다. 결과도 영어로 오니 "한국어로 설명해 줘", "결과물은 한국어로"를 붙이십시오.

남이 올린 글이라는 점을 잊지 마십시오 prompts.chat은 누구나 글을 올리는 곳입니다. 검색 결과에 test 같은 연습용 제목이 섞여 나오기도 했습니다. 클로드 코드 공식 문서도 바깥 내용을 가져오는 서버는 AI를 속이는 문장(프롬프트 주입)이 섞일 위험이 있다고 경고합니다. 스킬 안에는 실행되는 스크립트 파일이 들어 있을 수 있으니, 설치하기 전에 SKILL.md를 한 번 읽어 보라고 AI에게 부탁하십시오.

자주 묻는 질문

prompts.chat 회원 가입이나 API 키가 있어야 하나요?

찾아서 쓰기만 한다면 필요 없습니다. 키 없이도 서버의 검색 기능이 결과를 돌려주는 것을 확인했습니다. 내 프롬프트나 스킬을 저장하는 기능은 prompts.chat 설정 화면에서 받은 API 키가 있어야 합니다.

가져온 프롬프트를 제 블로그나 일에 그대로 써도 되나요?

prompts.chat은 프롬프트 내용과 데이터를 CC0 1.0으로 공개합니다. 사이트 안내에도 상업적 용도를 포함해 출처 표시 없이 쓸 수 있다고 적혀 있습니다. 다만 프롬프트로 만든 결과물이 사실과 맞는지는 직접 확인하셔야 합니다.

무료 클로드 계정에서도 연결할 수 있나요?

됩니다. 클로드 도움말에 따르면 무료 계정도 사용자 지정 커넥터를 쓸 수 있고, 1개까지 추가할 수 있습니다. 이미 다른 커넥터를 하나 쓰고 있다면 그것을 지우거나 요금제를 확인해야 합니다. 요금제 내용은 바뀔 수 있으니 클로드 공식 요금 페이지에서 확인하십시오.
