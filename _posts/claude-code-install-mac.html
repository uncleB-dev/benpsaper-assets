핵심 요약

  • Cmd + Space를 누르고 Terminal이라고 적어 터미널을 엽니다.
  • 명령 한 줄을 붙여 넣고 Enter를 누르면 설치가 끝납니다.
  • claude --version을 넣었을 때 (Claude Code)가 보이면 성공입니다.

이 글은 클로드 코드 왕초보 시리즈의 세 번째 편입니다. 맥에 클로드 코드를 설치합니다. 윈도우를 쓰신다면 윈도우 설치 편을 보시면 됩니다. 시리즈 목차는 글 아래에 있습니다.

해야 할 일은 하나입니다. 터미널이라는 창을 하나 열고, 정해진 한 줄을 붙여 넣고, Enter를 누르는 것입니다. 앱스토어에서 무엇을 내려받거나 설치 파일을 두 번 누를 일은 없습니다.

시작하기 전에 확인할 것

다음 두 가지만 맞으면 됩니다.

  1. 맥 운영체제 버전. macOS 13.0 이상이어야 합니다. 화면 왼쪽 위 사과 모양을 누르고 이 Mac에 관하여를 고르면 지금 버전이 나옵니다. 숫자가 13보다 작으면 먼저 업데이트를 하셔야 합니다.
  2. 인터넷 연결. 설치 파일을 인터넷에서 받아 오므로 연결이 되어 있어야 합니다.

계정은 지금 없어도 설치까지는 됩니다. 계정은 설치를 마치고 처음 실행할 때 필요합니다.

1단계. 터미널 창 열기

터미널은 글자로 컴퓨터에 말을 거는 창입니다. 마우스로 누를 버튼 대신 글자를 적어 넣는다고 생각하시면 됩니다.

  1. 키보드에서 Cmd 키와 Space 키를 같이 누릅니다. 화면 가운데에 검색칸이 뜹니다.
  2. 검색칸에 Terminal이라고 적습니다. 한글로 터미널이라고 적어도 찾아 줍니다.
  3. Enter를 누릅니다. 하얀색이나 검은색 창이 하나 열립니다.
  4. 줄 맨 앞에 사용자이름@맥이름 ~ % 같은 글자가 보이면 준비가 끝난 것입니다.

창 색이 하얗든 검든 상관없습니다. 맨 뒤에 %나 $ 기호가 있고 그 뒤에 글자를 적을 수 있으면 맞게 열린 것입니다.

2단계. 설치 명령 한 줄 붙여 넣기

아래 한 줄을 그대로 복사합니다.

curl -fsSL https://claude.ai/install.sh | bash
  1. 위 글자를 마우스로 끌어 선택한 뒤 Cmd + C로 복사합니다.
  2. 터미널 창을 한 번 누른 다음 Cmd + V로 붙여 넣습니다.
  3. 붙여 넣은 글자가 curl로 시작하는지 눈으로 확인합니다.
  4. Enter를 누릅니다.
  5. 글자가 주르륵 올라갑니다. 끝날 때까지 창을 닫지 말고 기다립니다.

설치가 잘 끝나면 초록색으로 Claude Code successfully installed!라고 나옵니다. 이 문장이 보이면 성공입니다.

이것만 조심하세요 붙여 넣은 줄이 irm으로 시작한다면 윈도우용 명령을 잘못 가져온 것입니다. 맥에서 그대로 실행하면 irm: command not found 같은 글이 나옵니다. 위 curl로 시작하는 줄을 다시 복사해 주십시오.

3단계. 잘 설치됐는지 확인하기

같은 창에 아래 한 줄을 넣고 Enter를 누릅니다.

claude --version

버전 번호 뒤에 (Claude Code)가 붙어 나오면 제대로 들어간 것입니다. 아래 그림처럼 보입니다. 앞의 숫자는 사람마다 다르니 달라도 걱정하지 않으셔도 됩니다.

command not found: claude라고 나온다면, 컴퓨터가 아직 새로 생긴 프로그램의 위치를 모르는 상태입니다. 터미널 창을 Cmd + Q로 완전히 끄고 다시 연 다음 같은 명령을 한 번 더 넣어 보십시오. 대부분 이것으로 해결됩니다. 그래도 같다면 아래 두 줄을 차례로 넣습니다.

echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc

첫 줄은 "프로그램이 여기 있으니 찾아보라"고 알려 두는 것이고, 둘째 줄은 그 내용을 지금 바로 적용하는 것입니다. 두 줄을 넣은 뒤 claude --version을 다시 해 보십시오.

4단계. 처음 실행하고 로그인하기

확인까지 되었으면 실제로 한번 실행해 봅니다. 아래 한 글자를 넣고 Enter를 누릅니다.

claude
  1. 처음이면 로그인하라는 안내가 나옵니다.
  2. 화살표 키로 원하는 항목을 고르고 Enter로 확정합니다. 이 창에서는 마우스 클릭이 되지 않습니다.
  3. 인터넷 창이 저절로 열리고, 거기서 로그인하고 승인을 누릅니다.
  4. 승인이 끝나면 터미널 창으로 돌아옵니다.

인터넷 창이 저절로 열리지 않으면 c를 눌러 주소를 복사한 다음, 인터넷 창 주소칸에 붙여 넣으시면 됩니다. 한 번 로그인해 두면 다음부터는 다시 묻지 않습니다. 계정을 바꾸고 싶을 때는 실행 중인 화면에서 /login이라고 넣으면 됩니다. 끝낼 때는 exit를 넣거나, 아무것도 적혀 있지 않은 입력칸에서 Ctrl + D를 누릅니다.

알아 두면 좋은 두 가지

  • 업데이트는 알아서 됩니다. 위 방법으로 설치하면 새 버전이 나올 때 배경에서 저절로 최신으로 바뀝니다. 손댈 것이 없습니다.
  • 홈브루를 쓰신다면 brew install --cask claude-code로도 설치할 수 있습니다. 다만 이 방법은 자동 업데이트가 되지 않아 가끔 brew upgrade claude-code로 직접 갱신해 주어야 합니다. 홈브루가 무엇인지 모르신다면 이 항목은 건너뛰셔도 됩니다.

자주 묻는 질문

맥 버전이 낮으면 어떻게 하나요?

클로드 코드는 macOS 13.0 이상에서 동작합니다. 그보다 낮은 버전에서는 실행할 때 built for Mac OS X 13.0 같은 문구와 함께 멈춥니다. 사과 메뉴에서 시스템 설정 > 일반 > 소프트웨어 업데이트를 열어 운영체제를 먼저 올리셔야 합니다.

터미널에 글자가 잔뜩 올라가는데 괜찮은가요?

정상입니다. 설치 중 무엇을 받고 있는지 보여 주는 것입니다. 마지막에 Claude Code successfully installed!가 보이면 잘 끝난 것입니다. 중간 글자를 읽으실 필요는 없습니다.

claude를 넣었더니 클로드 앱이 열립니다.

맥에 클로드 데스크톱 앱이 함께 깔려 있을 때 생길 수 있습니다. 데스크톱 앱을 최신 버전으로 업데이트하면 해결됩니다. 업데이트 뒤에도 같다면 터미널을 완전히 끄고 다시 열어 보십시오.
