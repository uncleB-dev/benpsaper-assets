핵심 요약

  • Win + X를 눌러 Windows PowerShell을 엽니다. 이름에 (x86)이 붙은 것은 열지 않습니다.
  • 명령 한 줄을 붙여 넣고 Enter를 누르면 설치가 끝납니다.
  • claude --version을 넣었을 때 (Claude Code)가 보이면 성공입니다.

이 글은 클로드 코드 왕초보 시리즈의 두 번째 편입니다. 윈도우 컴퓨터에 클로드 코드를 설치합니다. 맥을 쓰신다면 맥 설치 편을 보시면 됩니다. 시리즈 목차는 글 아래에 있습니다.

해야 할 일은 딱 하나입니다. 검은 창을 하나 열고, 정해진 한 줄을 붙여 넣고, Enter를 누르는 것입니다. 무엇을 직접 내려받거나 설치 프로그램을 실행할 필요는 없습니다. 아래 순서대로만 따라오시면 됩니다.

시작하기 전에 확인할 것

다음 두 가지만 맞으면 됩니다.

  1. 윈도우 버전. 윈도우 10 버전 1809 이상, 64비트여야 합니다. 요즘 쓰시는 컴퓨터라면 대부분 해당됩니다.
  2. 인터넷 연결. 설치 파일을 인터넷에서 받아 오므로 연결이 되어 있어야 합니다.

계정은 지금 없어도 설치까지는 됩니다. 계정은 설치가 끝나고 처음 실행할 때 필요합니다.

1단계. PowerShell 창 열기

PowerShell은 글자로 컴퓨터에 말을 거는 창입니다. 마우스로 누를 버튼 대신 글자를 적어 넣는다고 생각하시면 됩니다.

  1. 키보드에서 Win 키와 X 키를 같이 누릅니다. 화면 왼쪽 아래에 목록이 하나 뜹니다.
  2. 목록에서 Windows PowerShell을 누릅니다. 컴퓨터에 따라 터미널이라고 적혀 있을 수도 있습니다. 그것을 누르셔도 됩니다.
  3. 검고 파란 창이 열리고, 줄 맨 앞에 PS C:\Users\사용자이름> 같은 글자가 보입니다. 여기까지 오면 준비 끝입니다.

이 함정만은 피하세요 시작 메뉴에서 찾다 보면 Windows PowerShell (x86)이라는 것이 같이 보입니다. 이것은 32비트용이라, 이 창에서 설치하면 Claude Code does not support 32-bit Windows라는 오류가 납니다. 이름 뒤에 (x86)이 없는 것을 여십시오.

창 맨 앞 글자도 한번 봐 두시면 좋습니다. PS로 시작하면 PowerShell이고, PS 없이 C:\Users\사용자이름>로 시작하면 CMD라는 다른 창입니다. 이 글의 명령은 PowerShell용입니다.

2단계. 설치 명령 한 줄 붙여 넣기

아래 한 줄을 그대로 복사합니다.

irm https://claude.ai/install.ps1 | iex
  1. 위 글자를 마우스로 끌어 선택한 뒤 Ctrl + C로 복사합니다.
  2. PowerShell 창을 누른 다음 Ctrl + V로 붙여 넣습니다. 마우스 오른쪽 버튼을 한 번 눌러도 붙여 넣어집니다.
  3. 붙여 넣은 글자가 irm으로 시작하는지 눈으로 확인합니다.
  4. Enter를 누릅니다.
  5. 글자가 주르륵 올라갑니다. 끝날 때까지 창을 닫지 말고 기다립니다.

설치가 잘 끝나면 초록색으로 Claude Code successfully installed!라고 나옵니다. 이 문장이 보이면 성공입니다.

3단계. 잘 설치됐는지 확인하기

같은 창에 아래 한 줄을 넣고 Enter를 누릅니다.

claude --version

버전 번호 뒤에 (Claude Code)가 붙어 나오면 제대로 들어간 것입니다. 아래 그림처럼 보입니다. 숫자는 사람마다 다르니 숫자가 달라도 걱정하지 않으셔도 됩니다.

만약 'claude' is not recognized 같은 빨간 글씨가 나온다면, 컴퓨터가 아직 새 프로그램이 생긴 것을 모르는 상태입니다. PowerShell 창을 완전히 닫았다가 다시 열고 같은 명령을 한 번 더 넣어 보십시오. 대부분 이것으로 해결됩니다.

4단계. 처음 실행하고 로그인하기

확인까지 되었으면 실제로 한번 실행해 봅니다. 아래 한 글자를 넣고 Enter를 누릅니다.

claude
  1. 처음이면 로그인하라는 안내가 나옵니다.
  2. 화살표 키로 원하는 항목을 고르고 Enter로 확정합니다. 이 창에서는 마우스 클릭이 되지 않습니다.
  3. 인터넷 창이 저절로 열리고, 거기서 로그인하고 승인을 누릅니다.
  4. 승인이 끝나면 PowerShell 창으로 돌아옵니다.

인터넷 창이 저절로 열리지 않으면 c를 눌러 주소를 복사한 다음, 인터넷 창 주소칸에 붙여 넣으시면 됩니다. 한 번 로그인해 두면 다음부터는 다시 묻지 않습니다. 계정을 바꾸고 싶을 때는 실행 중인 화면에서 /login이라고 넣으면 됩니다.

끝낼 때는 exit를 넣거나, 아무것도 적혀 있지 않은 입력칸에서 Ctrl + D를 누릅니다.

알아 두면 좋은 두 가지

  • 업데이트는 알아서 됩니다. 위 방법으로 설치하면 새 버전이 나올 때 배경에서 저절로 최신으로 바뀝니다. 손댈 것이 없습니다.
  • Git for Windows는 선택입니다. 같이 설치하기를 권하긴 하지만, 없어도 클로드 코드는 PowerShell을 대신 사용합니다. 나중에 설치하고 싶다면 git-scm.com/downloads/win에서 받으면 되고, 설치 중 "Adjusting your PATH environment" 화면은 권장으로 표시된 것을 그대로 두고 넘어가시면 됩니다.

덧붙여, 회사 컴퓨터처럼 설정이 까다로운 환경에서는 위 방법 대신 winget install Anthropic.ClaudeCode로 설치할 수도 있습니다. 다만 이 방법으로 설치하면 자동 업데이트가 되지 않아 가끔 직접 갱신해 주어야 합니다.

자주 묻는 질문

붙여 넣기가 안 됩니다. 어떻게 하나요?

PowerShell 창을 한 번 눌러 활성 상태로 만든 뒤 Ctrl + V를 누르십시오. 그래도 안 되면 창 안에서 마우스 오른쪽 버튼을 한 번 누르면 복사해 둔 글자가 바로 들어갑니다.

CMD 창에서 해도 되나요?

CMD에서는 이 글의 명령이 동작하지 않습니다. 'irm' is not recognized라는 오류가 나옵니다. CMD에서 설치하려면 curl -fsSL https://claude.ai/install.cmd -o install.cmd로 시작하는 CMD 전용 명령을 써야 합니다. PowerShell을 여는 쪽이 간단합니다.

설치한 뒤 claude를 넣으면 인식이 안 된다고 나옵니다.

창을 완전히 닫고 새 PowerShell 창에서 다시 해 보십시오. 그래도 같다면 설치 위치가 컴퓨터에 등록되지 않은 경우입니다. 시리즈의 오류 해결 편에 등록하는 방법을 정리해 두었습니다.
