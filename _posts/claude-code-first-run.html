핵심 요약

  • 연습 폴더에서 claude를 치면 클로드 코드가 시작되고, 처음에는 로그인 안내가 나옵니다.
  • 브라우저에서 승인만 하면 끝입니다. 브라우저가 안 열리면 c를 눌러 주소를 복사합니다.
  • 우리말로 "파일 하나 만들어 줘"라고 시켜 보면, 왼쪽 파일 목록에 진짜로 파일이 생깁니다.

이 글은 클로드 코드 왕초보 시리즈의 여섯 번째 글입니다. 앞 글에서 만든 연습 폴더를 VS Code로 열어 두셨다면 준비는 끝났습니다. 이번에는 클로드를 처음 깨워서 첫 파일 하나를 만들어 보는 것까지만 합니다. 딱 그것만 합니다.

시작 전에 한 가지만 확인하십시오. VS Code 왼쪽에 claude-practice 같은 폴더 이름이 보여야 합니다. 안 보이면 File > Open Folder...로 폴더부터 여십시오. 클로드 코드는 "지금 있는 폴더" 안에서 일하기 때문에, 자리를 잘못 잡으면 엉뚱한 곳에 파일이 생깁니다.

1단계 · claude 실행하고 로그인하기

  1. VS Code에서 Terminal > New Terminal로 아래쪽 터미널을 엽니다.
  2. 아래 다섯 글자를 그대로 치고 Enter를 누릅니다.
claude
  1. 처음이라면 로그인하라는 안내가 나옵니다. 화살표 키로 로그인 방법을 고르고 Enter를 누릅니다.
  2. 브라우저가 저절로 열리면서 승인 화면이 나옵니다. 내 계정이 맞는지 보고 승인을 누릅니다.
  3. 브라우저가 안 열리면 터미널에서 c를 누르십시오. 로그인 주소가 복사됩니다. 브라우저 주소창에 붙여넣고(Ctrl + V) 들어가면 됩니다.
  4. 승인이 끝나면 터미널로 돌아옵니다. 아래쪽에 글자를 칠 수 있는 입력칸이 생기면 성공입니다.

로그인은 한 번만 하면 됩니다. 다음부터는 claude만 치면 바로 시작됩니다. 계정을 바꾸고 싶으면 입력칸에 /logout을 쳐서 나간 뒤 /login으로 다시 들어가면 됩니다.

2단계 · 이 화면을 쓰는 법

여기는 카톡 채팅방과 비슷하지만, 몇 가지가 다릅니다. 이것만 알면 됩니다.

  • 마우스로 눌러도 아무 일이 없습니다. 고르는 것은 ↑ ↓ 화살표 키로 하고, 정하는 것은 Enter입니다.
  • 클로드가 한창 일하는 중에 멈추고 싶으면 Esc를 누릅니다. 하던 말은 남아 있으니 다시 시켜도 됩니다.
  • 아까 친 문장을 다시 쓰고 싶으면 ↑를 누릅니다. 지난 입력이 올라옵니다.
  • 입력칸 맨 앞에 /를 치면 쓸 수 있는 명령 목록이 뜹니다. 문장 중간에 적으면 그냥 글자로 봅니다.
  • 끝낼 때는 /exit를 칩니다. 빈 입력칸에서 Ctrl + D를 눌러도 됩니다.

단축키는 쓰는 컴퓨터와 터미널 종류에 따라 조금씩 다를 수 있습니다. 궁금하면 입력칸에서 ?를 눌러 보십시오. 지금 쓸 수 있는 단축키가 그대로 나옵니다.

3단계 · 첫 파일 만들어 보기

이제 시켜 봅니다. 우리말로 말해도 됩니다. 아래 한 줄을 그대로 복사해 입력칸에 붙여넣고 Enter를 누르십시오.

hello.txt 라는 파일을 만들고, 그 안에 "클로드 코드 첫날"이라고 한 줄만 써 줘.

잠깐 글자들이 지나간 뒤 다 했다는 말이 나옵니다. 그러면 VS Code 왼쪽 파일 목록을 보십시오. hello.txt가 새로 생겨 있습니다. 한 번 눌러 보면 방금 시킨 문장이 안에 들어 있습니다. 이것이 클로드 코드가 하는 일의 전부입니다. 말로 시키면, 진짜 파일이 생깁니다.

이어서 고쳐 보는 것도 해 보십시오. 방금 만든 파일을 이렇게 고칠 수 있습니다.

hello.txt 에 오늘 날짜를 한 줄 더 붙여 줘.

4단계 · 물어보는 화면과 권한 모드

클로드가 파일을 만들기 전에 "해도 되냐"고 물어보는 화면이 뜰 때가 있습니다. 뜨면 화살표로 고르고 Enter를 누르면 됩니다.

다만 요즘은 안 물어보고 바로 하는 경우가 더 많습니다. Pro·Max·Team 요금제로 터미널에서 대화할 때는 자동 모드로 시작하기 때문입니다. 자동 모드에서는 따로 심사하는 역할이 대신 검토해서, 평범한 일은 묻지 않고 진행하고 위험해 보이는 일만 막습니다. 다른 요금제는 매번 물어보는 수동 모드로 시작합니다.

지금 내가 어느 쪽인지는 입력칸에 이렇게 쳐서 볼 수 있습니다.

/status

모드를 바꾸고 싶으면 Shift + Tab을 누릅니다. 누를 때마다 모드가 돌아가며 바뀝니다. 그중 계획 모드는 파일을 건드리지 않고 "이렇게 할게요"라는 계획만 보여 주는 모드입니다. 계획 모드로 들어가면 화면에 ⏸ plan mode on이라고 표시됩니다. 남의 중요한 폴더에서 처음 일을 시킬 때 쓰면 마음이 놓입니다.

겁내지 않으셔도 되는 이유 방금 한 일이 마음에 안 들면 Esc를 두 번 누르거나 /rewind를 치십시오. 대화만 되돌릴지, 파일까지 되돌릴지 고를 수 있습니다. 그래도 불안하면 연습 폴더처럼 없어져도 괜찮은 폴더에서만 연습하십시오. 중요한 파일이 든 폴더는 나중에 익숙해진 다음에 여십시오.

5단계 · 끄고, 다음에 이어 하기

오늘은 여기까지입니다. 입력칸에 /exit를 쳐서 나가십시오. 컴퓨터를 꺼도 만들어 둔 파일은 폴더에 그대로 남습니다.

다음에 이어서 하려면 같은 폴더에서 다시 claude를 치면 됩니다. 어제 하던 이야기를 그대로 이어서 하고 싶다면 이렇게 실행하십시오.

claude -c

여러 개 중에 골라서 이어 가고 싶으면 claude -r을 쓰면 목록이 나옵니다. 이어 갈 대화가 없으면 No conversation found to continue라고 나오는데, 이것도 오류가 아니라 그냥 "이어 갈 것이 없다"는 뜻입니다.

자주 묻는 질문

로그인 화면에서 브라우저가 안 열립니다.

터미널에서 c를 누르면 로그인 주소가 복사됩니다. 브라우저를 직접 켜고 주소창에 붙여넣어(Ctrl + V) 들어가면 같은 승인 화면이 나옵니다. 승인한 뒤 터미널로 돌아오면 이어집니다.

영어로 시켜야 더 잘 알아듣나요?

우리말로 시켜도 됩니다. 중요한 것은 어느 나라 말이냐가 아니라 무엇을 어디에 만들지 분명히 적었느냐입니다. 시키는 문장을 쓰는 요령은 다음 편에서 따로 다룹니다.

클로드가 엉뚱한 곳에 파일을 만들었습니다.

터미널이 다른 폴더에서 시작했을 가능성이 큽니다. 터미널 줄 앞에 적힌 위치가 연습 폴더로 끝나는지 확인하십시오. 아니라면 /exit로 나가서 VS Code로 폴더를 다시 연 뒤 claude를 다시 실행하면 됩니다.
